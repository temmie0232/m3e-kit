開閉 — <details> で作る

なぜ <details> を使うのか
開閉の状態・キーボード操作・読み上げ・ページ内検索をブラウザが持つから。 div と JS で作り直すと、そのどれかが必ず抜ける。
高さのアニメーションは？
interpolate-size と ::details-content が入った環境では滑らかに開く。 入っていない環境では瞬間的に開くだけで、壊れない。
