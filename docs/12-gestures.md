# 12. ジェスチャー

## 原則

**指の移動量に対して、画面が 1:1 でリアルタイムに反応すること。**

時間指定のアニメーションで「それっぽく」動かすのと、指に付いてくるのとは
まったく違うものになる。ここが「Web ページ」と「アプリ」の分かれ目。

離したら**離した速度を引き継いで**バネで収める（→ [07-motion](07-motion.md)）。

---

## 標準のジェスチャー

| ジェスチャー | 挙動 |
|---|---|
| 全画面ビューアの下スワイプ | 指に 1:1 追従（位置・縮小・角丸・地の不透明度）。`dy > H×0.22` または `v > 800px/s` で閉じ、元のタイルへ吸い込まれる |
| 横スワイプ（ページ送り） | 前後へ。吸着。専用のバネ（剛性 700 / 減衰 50）でテンポを作る |
| ピンチ / ダブルタップ | 拡大縮小 / 等倍トグル。**ズーム中は横スワイプを無効にする** |
| リストの左スワイプ | 削除。幅の 40% で予告が変わる（`error-container → error`） |
| ボトムシートの引き下ろし | 1:1 追従。高さの 30% または速度で閉じる |
| 下に引く | 更新。読み込みの印が育つ（形が変わる）。最上部で同じタブをもう一度押しても同じ道 |
| 端末の戻る | **1枚ずつ閉じる**（シート → ビューア → 階層 → タブ）。足あとが空になって初めて終了 |

---

## ラバーバンド（端での抵抗）

限界を超えた分に抵抗を掛ける。iOS のスクロールと同じ式:

```
offset = (x · d · c) / (d + c · x)      c = 0.55、d = 画面の寸法
```

`lib/motion.ts` の `rubber(x, dimension, c)`。

これが無いと、端で「止まった」のか「反応していない」のか区別できない。

---

## 速度を引き継ぐ

```ts
import { VelocityTracker } from './lib/motion'

const v = new VelocityTracker()
// pointermove ごとに v.add(e.clientY, e.timeStamp)
// pointerup で
const speed = v.velocity()      // px/s
springSettle(el, target, speed) // 初速として渡す
```

**★指が止まってから離した場合は速度 0★** 直近のサンプルだけで加重平均を取り、
古いサンプルは捨てる。これをしないと「ゆっくり戻したのに勢いよく飛ぶ」。

---

## 中断可能にする

再生中のアニメーションに指が触れたら、**その位置から掴み直せる**。

```ts
import { freezeInto } from './lib/motion'
freezeInto(el)   // 走行中の Animation を全部 cancel し、いまの見た目を inline style に固める
```

★これがあるので、掴める要素に CSS の `@keyframes` を足してはいけない★
（→ [07-motion](07-motion.md)）

## touch-action を正しく書く

ブラウザに任せる方向と、自分で拾う方向を宣言する。

| 部品 | 値 |
|---|---|
| 横に引く行 | `touch-action: pan-y`（縦スクロールはブラウザ） |
| 上下に払うスナックバー | `touch-action: pan-x` |
| 掴んで動かすシートのつまみ | `touch-action: none` |
| 拡大できる画像 | `touch-action: none`（全部自前） |
| 引いて更新する一覧 | 触らない（`touch-action` は既定のまま）。引いている間の `touchmove` だけ止める |

書き忘れると、ブラウザのスクロールと自前の処理が競合して「たまに効かない」になる。

**★Pointer Events の `preventDefault` ではスクロールは止まらない★**
止めるのは `touch-action` だけ。スクロールする要素の上で「引いている間だけ」
止めたいときは、`touchmove` を `{ passive: false }` で拾って
そこで `preventDefault()` する（→ 下の「引いて更新」）。

## 引いて更新

```ts
import { attachPullToRefresh } from './lib/ptr'

attachPullToRefresh(main, ptr, async () => { await reload() })
```

HTML は `.app` の直下に `.ptr` を1つ（→ [09-components](09-components.md#引いて更新)）。

| | |
|---|---|
| 動くもの | **印だけ。** 一覧は動かさない |
| 追従 | しきい値までは **1:1**。越えた分だけ `rubber(dy - 72, 240)` で抵抗（上限 112px）。同じ量で**形の再生位置**も進む |
| しきい値 | 印が完全に出きる位置（72px）。到達した瞬間に `haptic('light')` |
| 離したら | 届いていれば 72px でバネで止め、`.loader--on` を付けて回す。届いていなければ仕舞う |
| 終わり | `onRefresh()` の Promise が解決したら、回転を止めて仕舞う |

- **★一覧ごと下げない★** 離した瞬間に中身が跳ねて「どこを読んでいたか」が消える。
  これが「引いて更新」で一番多い失敗
- **★引いている間は回さない★** 回転は「待っている」の合図。
  引いている間は形が育つだけにしておかないと、指を離す前から終わったように見える
- 引ける条件は `scrollTop <= 0`。上へ動いた時点で手を引いてブラウザに返す
  （途中で「やっぱりスクロール」ができないと、一覧の先頭が重くなる）
- 最上部で同じタブをもう一度押したときも、同じ更新を通す

---

## タップ判定

- 最小 **48×48**
- 見た目が小さいものは `::after` で判定だけ広げる（→ [05-space](05-space.md)）
- 隣接するタップ要素の間隔は最低 8px
- 押下の反応は **100ms 以内**（`pointerdown` で `.is-pressed`）

---

## ハプティクス

```ts
import { haptic } from './lib/motion'
haptic('selection')
```

| 種類 | いつ |
|---|---|
| `selection` | 切替（タブ・チップ・スイッチ） |
| `light` | 押下・しきい値に到達した瞬間 |
| `medium` | 長押し・モード切替 |
| `success` / `error` | 完了・失敗 |

**★スクロール中に鳴らし続けない★** 連続で鳴ると、端末が熱くなり、
何を知らせているのか分からなくなる。

Android (Chrome) は `navigator.vibrate` が効く。iOS Safari には無いので黙って
何もしない（`haptic()` の中で吸収済み）。

---

## 端末の戻るボタン

Android では**必ず**1枚ずつ閉じる。

```
シート → 全画面ビューア → 階層（フォルダ）→ タブの履歴 → アプリ終了
```

足あと（スタック）を持ち、`popstate` か Capacitor の `backButton` で1つ取り出す。
**いきなりアプリが終わるのが最悪の体験。** 深い階層から一発で戻したいなら、
それは「戻る」ではなく画面内の別の操作にする。
