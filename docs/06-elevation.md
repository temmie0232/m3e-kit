# 06. 高さ（面と影）

## 高さは2つの手段で表す

1. **明度** … surface container の5段。**これが既定**
2. **影** … `--elev-1`〜`--elev-5`。**浮いているものにだけ**

同じものに両方を使わない。カードは明度だけ、FAB は影だけ（+ primary-container）。

---

## 影を敷いてよいもの

| 部品 | 影 | 理由 |
|---|---|---|
| FAB | `--elev-3` | 本当に画面から浮いている |
| 浮くツールバー | `--elev-3` | 中身の上に重なっている |
| スナックバー | `--elev-3` | 一時的に上に載る |
| ダイアログ | `--elev-3` | 暗幕 + 影 |
| 読み込みの印の器 | `--elev-2` | 引くと降りてくる |
| ボトムシート | `--elev-1` | 暗幕が主役なので影は控えめ |
| 上から降りてくる札 | `--elev-2` | |
| **カード・パネル・行** | **なし** | 明度差だけ。ここに影を敷くと画面全体が汚れる |
| **トップアプリバー・ナビゲーションバー** | **なし** | M3 は色の変化だけで潜りを表す |

一覧に数百行あるとき、行に影があるとスクロールのたびに全部を描き直す。
明度差なら合成コストは実質ゼロ。

---

## 影の作り

M3 の影は **umbra（近い・濃い）と penumbra（遠い・薄い）の2層**。
1層の `box-shadow` では M3 に見えない。

```css
--elev-3:
  0 1px 3px rgb(var(--shadow-rgb) / 0.3),
  0 4px 8px 3px rgb(var(--shadow-rgb) / 0.15);
```

色は `--shadow-rgb`（生成された shadow 色）から取る。黒を直書きしない。

---

## 面を重ねる順番

```
surface          画面の地
 └ surface-low       ボトムシート
    └ surface-mid       カード・行・バー
       └ surface-high      ダイアログ・通知・浮くツールバー
          └ surface-highest   入力欄・トラック・骨
```

**必ず1段ずつ上げる。** `surface` の上にいきなり `surface-highest` を置くと、
段が飛んで「浮いている」ではなく「別のもの」に見える。

例外は「沈めたいもの」。コード欄・引用は `surface-lowest`（ライトでは白）で、
地より**下**に見せる。

### 入れ子の中の面

`surface-mid` のカードの中に置く入力欄は `surface-highest` でよい（2段上）。
これは「カードの中でさらに1段」ではなく「入力欄はいつも highest」という
役割の固定。役割 > 相対位置。

---

## ぼかしを使わない理由

`backdrop-filter` は 1 箇所も書かない。

- 背後のピクセルを読み戻すので、スクロール中に一番重い（GPU の読み戻しは
  合成スレッドを止める）
- 半透明の板は背後の内容によって文字のコントラストが変わる。
  「白い写真の上を通過した瞬間だけ読めない」が起きる
- 明度差なら、ライト/ダークの両方が配色の生成側で自動的に整う

`grep -r backdrop-filter src/` が 0 件であることをチェックリストで確認する。

半透明を使わないので、OS の「透明度を下げる」設定への逃げ道も要らなくなる。
