# 05. 間隔とレイアウト

4px 基準。`--s-1`(4) `--s-2`(8) `--s-3`(12) `--s-4`(16) `--s-5`(20) `--s-6`(24)
`--s-8`(32) `--s-10`(40)。

**線ではなく距離で分ける。** 関係が近いものほど近づける。区切り線は
「距離では足りないとき」の最後の手段。

---

## 画面の律動は2段階まで

1画面の中で3種類以上の間隔を使うと、どれが切れ目なのか読めなくなる。

| | 値 |
|---|---|
| 話題が変わる（セクション間） | 24（`--s-6`） |
| 同じ話題の中（セクション内の要素間） | 16（`--s-4`）または 12（`--s-3`） |

セクションで話題を括る画面（設定・ダッシュボード）は 24 を地に、
操作と中身が交互に積まれる画面（一覧・エディタ）は 16 を地にする。

---

## ★間隔は必ず1箇所で持つ★（一番踏む事故）

`gap` を持つ列の子に `margin` を足すと、**両方が効いて足し算になる**。

```css
.list { display: flex; flex-direction: column; gap: var(--s-4); }
.item + .item { margin-top: var(--s-5); }   /* ❌ 16 + 20 = 36 の穴が開く */
```

**兄弟の間隔は `gap` だけで作る。個別の `margin` を書かない。**

### 派生: 当たり判定を内側に抱えた部品

```css
.chips { padding-block: 8px; }   /* .chip::after の上下 8px を抱えるため */
```

こういう部品を `gap` の列に置くと、その `padding` が `gap` に上乗せされて
**その帯の周りだけ間隔が 24 になる**（16 のつもりが）。画面の律動がそこで途切れる。

打ち消すのは `padding` ではなく `margin`:

```css
.main--padded > .chips { margin-block: calc(var(--s-2) * -1); }
```

`padding` を削ると当たり判定まで減るが、負の `margin` なら 48px の判定は 1px も減らない。

---

## ★伸び代を同じ行に2つ置かない★

```html
<div style="display:flex; gap:8px">
  <div class="seg" style="flex:1">…</div>   <!-- ❌ -->
  <div class="seg" style="flex:1">…</div>   <!-- ❌ 幅を山分けする -->
</div>
```

`flex: 1` を同じ行に2つ置くと、余った幅ではなく**全体を山分け**する。
どちらかが痩せて、中の和文ラベルが2行に折れる。

- 伸びてよいものは行に**1つだけ**
- 残りは `flex: 0 0 auto`
- 「両方伸ばしたい」は、たいてい「その行に置くものが多すぎる」のサイン

同じ理由で、見出しの隣に置くボタンは必ず `flex: 0 0 auto; white-space: nowrap`。
左の説明文が長いとボタンだけが押し潰されて縦書きになる。
**詰めを引き受けるのは文の側で正しい。**

---

## ★スクロールする列の中身を縮ませない★

「高さが決まった flex 列」かつ `overflow-y: auto` では、中身が入りきらないとき
flex はまず子を縮めようとする。`overflow: hidden` を持つカードや
`overflow-x: auto` を持つチップの帯は最小サイズが 0 になるので、
**黙って潰れてスクロールが出ない**。

```css
.main.main--padded > * { flex-shrink: 0; }
```

★セレクタを2つ重ねる★ 詳細度を (0,2,0) にして、`.seg { flex: 1 }` のような
(0,1,0) に読み込み順と無関係に勝たせる。

ボトムシートの中でも同じ罠を踏む（`.sheet .sheet__body > *`）。

## grid の列

```css
grid-template-columns: repeat(3, minmax(0, 1fr));   /* ✅ */
grid-template-columns: repeat(3, 1fr);              /* ❌ = minmax(auto, 1fr) */
```

素の `1fr` は「中身の最小幅」より小さくならない。和文の最小幅は1文字なので
日本語ラベルには効かず、幅が足りないと黙って2行に折れる
（→ [04-type](04-type.md) の「和文の最小幅は1文字」）。

0 まで縮めてよいことにして、溢れは子側で `text-overflow: ellipsis` で受ける。

## タップ判定

- 最小 **48×48**
- 見た目が小さいもの（小ボタン 32、チップ 32、スナックバーの操作 36）は
  `::after` で**当たり判定だけ**広げる

```css
.btn--sm::after,
.chip::after {
  content: '';
  position: absolute;
  inset: -8px -4px;
}
```

見た目の `padding` を増やして 48px にすると、画面全体がゆるむ。

- 隣接するタップ要素の間隔は最低 8px
- `::after` を使う要素は `position: relative` が要る
- **`overflow: hidden` / `overflow-x: auto` の中では `::after` がクリップされる。**
  親に `padding-block` を持たせて逃がす（上の `.chips` を参照）

## 画面の幅

```css
.app { max-width: 720px; margin-inline: auto; }
```

タブレット・PC で間延びさせない。720 を超えたら左右に `--outline-variant` の
1px を出して、板が置かれていることを示す。
