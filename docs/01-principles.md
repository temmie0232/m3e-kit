# 01. 大原則

この5つに反する実装をしない。以降の章は全部この5つの言い換え。

---

## 1. 色は意味を持つ。装飾のために色を使わない

| 色 | 意味 |
|---|---|
| `primary` | 主要操作・いま見ているデータ・グラフの1系列目 |
| `primary-container` | FAB・読み込みの印の器・「有効」のバッジ |
| `secondary-container` | **選択されている**（チップ・行・タイル・ナビの選択ピル）、tonal ボタン |
| `tertiary-container` | 2系列目（1系列目と区別が要るときだけ） |
| `error` / `error-container` | 超過・期限切れ・削除の予告・失敗の通知 |
| `surface-*` | 面の高さ（5段） |

同じ色が2つの意味を持った時点で、その画面は読めなくなっている。
「なんとなく賑やかにしたい」で色を足さない。

---

## 2. 層は明度で作る。ぼかしは使わない

`backdrop-filter` は 1 箇所も書かない。面の高さは surface container の
5段階（lowest / low / mid / high / highest）と elevation（影）で表す。

理由は3つ。
- ぼかしは背後のピクセルを読み戻すので、スクロール中に一番重い
- 半透明の板は背後の内容によって文字のコントラストが変わる（読めない瞬間が出る）
- 明度差なら、ライト/ダークの両方が配色の生成側で自動的に整う

→ [06-elevation](06-elevation.md)

---

## 3. 形が動く。縮めない

ボタン・FAB・チップは、押している間だけ **`border-radius` が変わる**
（丸 → 角丸）。これが Expressive の shape morph。

- ❌ `transform: scale(0.96)` … 「押した」ではなく「壊れた」に見える
- ❌ `opacity: 0.6` … 消えかけているように見える
- ✅ 形が変わる + 状態レイヤー（地の上に on-色を 10% 重ねる）

→ [03-shape](03-shape.md)

---

## 4. 動きはバネ。時間と曲線ではない

M3 Expressive の motion scheme は「duration + easing」ではなく
**バネ（剛性と減衰比）**で定義されている。

- 位置・大きさ・形 → `spatial`（少し行き過ぎてよい）
- 色・不透明度 → `effects`（行き過ぎない＝臨界減衰）

指由来の動きは全部バネで戻す。時間指定の ease では「投げた強さ」が画面に伝わらない。

→ [07-motion](07-motion.md)

---

## 5. 迷ったら1つ減らす

- 1画面1目的
- タップできるものは7個以下（ナビゲーションバーを除く）
- 画面の中の余白の種類は2つまで（「話題が変わる」24 / 「同じ話題の中」16）
- 主要操作（filled ボタン）は1画面に1つ

足したくなったら、まず何を消せるかを考える。

---

# やらないことリスト

- ❌ `backdrop-filter`、ガラスの縁光、半透明の板
- ❌ 押下で `scale` / `opacity`（形と状態レイヤーで返す）
- ❌ `linear` イージング（無限に回るものだけ例外）、長い `ease-in-out`
- ❌ 0.5px の hairline（区切りは `--outline-variant` 1px か余白）
- ❌ 手書きの hex 色（写真・動画の上に置くものを除く）
- ❌ `primary-container` の上に `primary` の文字（同系のコントラスト不足）
- ❌ 全画面スピナー、「エラーが発生しました」だけのメッセージ
- ❌ 和文の負の字間、`text-transform: uppercase` + 字間
- ❌ 確認ダイアログの多用（取り消せる設計にしてスナックバーで戻す）
- ❌ 兄弟の間隔を個別 `margin` で作る（`gap` と足し算になる）
- ❌ トークンに無い数値の直書き

# なぜ Web で自前に起こすのか

Google は M3 Expressive の Web 向け公式実装を出していない。

- `@material/web`（Web Components）は**保守モード**で、Expressive に対応しない
- Compose（Android）と Flutter には実装がある。仕様の一次情報はそちら側
- `@material/material-color-utilities` は**配色の計算だけ**を提供する。
  これは使う（ただしビルド時だけ。実行時に読み込まない）

だから「M3 のライブラリを入れる」という選択肢は最初から無い。
`m3.material.io` の仕様（色・形・字・動き）を CSS に起こしたものが `starter/`。
